# Kymo

Instaladores de Kymo, la app de escritorio que pone tu trabajo bajo control, y el de tu equipo: tus tareas, lo que te piden y tus objetivos en un solo lugar.

**Descarga:** https://kymo-app.github.io/releases/

Kymo tiene tres planes: Free (gratis, en tu computador), Pro y Team (muy pronto, con 14 días gratis). La app de celular, para Pro y Team, llega muy pronto a iPhone y Android.

Cada versión está en [Releases](https://github.com/kymo-app/releases/releases). La app revisa este repositorio para avisar de versiones nuevas y, en Windows, actualizarse sola.

Este repositorio solo tiene la página de descarga (`index.html`) y los instaladores; el código de la app no es público.
