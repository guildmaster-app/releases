# Guildmaster

Instaladores de Guildmaster, una app de escritorio que organiza tu trabajo.

**Descarga:** https://guildmaster-app.github.io/releases/

Cada versión está en [Releases](https://github.com/guildmaster-app/releases/releases). La app revisa este repositorio para avisar de versiones nuevas y, en Windows, actualizarse sola.

Este repositorio solo tiene los instaladores; el código de la app no es público.
